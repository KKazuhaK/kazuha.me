# 0001 · 不引入 UI 框架

日期：2026-11-04 · 状态：已采纳

## 背景

最初计划用 React islands 做三个有状态组件：手机菜单、语言切换和项目筛选。选 React 主要是为了以后方便扩展。

## 决定

这三个组件都用原生 HTML 加少量内联 `<script>` 实现，不安装 `@astrojs/react`。

- 手机菜单：一个 `<button aria-expanded>` 控制面板的 `hidden`。
- 语言切换：两个普通链接，没有状态。
- 项目筛选：几个 `aria-pressed` 按钮切换卡片的 `hidden`；没有脚本时显示全部卡片。

## 理由

- 少一个运行时依赖，也没有 hydration 开销，更容易达到 Lighthouse ≥ 90。
- 这三个组件的状态都只有一两个布尔值，用框架换不来什么。
- 以后真有复杂交互，`npx astro add react` 一条命令就能加上，现有组件不用改。

## 何时重新考虑

出现需要客户端渲染列表、表单校验或跨组件共享状态的功能时。
