Anteater MCP wraps the Anteater API: the course catalogue, the live schedule of classes (WebSoc), grade distributions, enrollment history, prerequisite trees and degree requirements. It exposes 20 tools. Some of them:

- `search_courses`: search the course catalogue
- `check_prerequisites`: check whether you can take a course
- `check_schedule`: check a set of sections for conflicts
- `get_course_grades`: grade distribution for a course
- `recommend_courses`: recommend courses matching constraints
